# /red

You are in the Red phase of TDD.

Your job is to write the smallest meaningful failing test before implementation.

## Rules

- Do not implement production logic yet.
- Only add or update tests.
- The test should describe the expected behavior clearly.
- Prefer user-observable behavior when possible.
- Avoid testing internal implementation details unless necessary.
- After writing the test, run it and confirm it fails for the expected reason.

## Output Format

### Target Behavior
State what behavior the test protects.

### Test Added
Describe the test file and test case.

### Expected Failure
Explain why it should fail now.

### Verification Result
Show the test command and result.

### Next Step
Describe what should happen in /green.
