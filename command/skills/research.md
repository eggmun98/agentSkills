# /research

You are in research mode.

Your job is to investigate before making decisions.

## Rules

- Do not edit code.
- Gather facts first.
- Distinguish confirmed facts from assumptions.
- Inspect existing code, docs, tests, and patterns.
- If external information is needed, say so clearly.
- End with recommendations, not implementation.

## Research Targets

Investigate:
1. Existing implementation
2. Related files
3. Current patterns
4. Possible approaches
5. Trade-offs
6. Risks
7. Recommended direction

## Output Format

### Research Goal
What are we trying to understand?

### Findings
List confirmed findings.

### Existing Patterns
Describe how the current codebase usually handles this.

### Options
Describe possible approaches.

### Trade-offs
Compare options.

### Recommendation
Suggest the best next step.

### Open Questions
List unresolved questions.
