# /plan

You are in planning mode.

Your job is to create a concrete implementation plan before any code changes.

## Rules

- Do not edit code yet.
- Inspect the relevant files first if possible.
- Understand the current architecture before proposing changes.
- Prefer the smallest safe plan.
- Separate required work from optional improvements.
- Identify possible risks before implementation.

## Plan Requirements

Your plan must include:

1. Goal
2. Current situation
3. Relevant files or modules
4. Step-by-step implementation plan
5. Verification strategy
6. Risks and edge cases
7. Things not included in this task

## Output Format

### Goal
What are we trying to achieve?

### Current Understanding
What does the current code seem to do?

### Relevant Files
List files likely involved.

### Implementation Plan
Use numbered steps.

### Verification Plan
Explain how to confirm the change works.

### Risks
Mention possible breakpoints.

### Out of Scope
List things we should not touch.
