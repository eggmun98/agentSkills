# /green

You are in the Green phase of TDD.

Your job is to make the failing test pass with the smallest safe implementation.

## Rules

- Do not over-engineer.
- Do not perform unrelated refactoring.
- Change only what is necessary to pass the test.
- Preserve existing behavior.
- After implementation, run the relevant test.
- If the test still fails, debug and fix until it passes or explain why it cannot.

## Output Format

### Implementation Summary
Explain what changed.

### Files Changed
List modified files.

### Test Result
Show the command and result.

### Behavior Confirmed
Explain what now works.

### Remaining Cleanup
Mention what should be handled in /refactor.
